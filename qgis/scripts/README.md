# QGIS Processing Scripts

This folder contains the Python scripts used to perform the geometric characterization of the residential building stock of Álava in QGIS.

## Workflow

The scripts process cadastral information and digital surface models to generate the geometric and physical parameters required by the thermal characterization stage.

## Execution

The original workflow is launched through `Script_QGIS.py` using the QGIS Python console.

## Script Organization

The original methodology includes 22 processing scripts and additional scripts for cleaning and resetting the processing environment.

The scripts will be added and documented individually after their contents have been reviewed.

## Requirements

- QGIS 3.42.3
- Python environment integrated into QGIS
- Required cadastral and raster input datasets

## Notes

Preserve the original script filenames and execution order when adding the files to this repository.
