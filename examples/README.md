# Examples

This folder contains example datasets and files illustrating how to use the geometric and thermal characterization methodology.

## Purpose

The examples are intended to help users understand the expected input data structure, processing workflow and output format.

## Planned Contents

- Example cadastral datasets.
- Example digital surface model data.
- Example climatic input data.
- Sample processing outputs.
- Example maps and visualizations.

## Data Management

Whenever possible, examples should use small datasets that are suitable for testing and demonstration.

All example data should have clearly documented sources and usage conditions.
