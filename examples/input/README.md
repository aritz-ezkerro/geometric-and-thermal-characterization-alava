# Example Input Data

This folder contains small example datasets illustrating the input format required by the methodology.

## Planned Contents

- Sample cadastral data.
- Example digital surface model raster files.
- Example climatic data.

## Purpose

These datasets will allow users to understand how input files should be organized before running the QGIS and Python workflows.

## Notes

Example datasets should be small, clearly documented and suitable for demonstration purposes.

Their sources and usage conditions must be indicated.
