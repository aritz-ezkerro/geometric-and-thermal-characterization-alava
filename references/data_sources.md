# Data Sources

This file documents the main data sources used in the geometric and thermal characterization of the residential building stock of Álava.

## 1. Cadastral Data

**Source:** Catastro de Álava (Álava Cadastre).

**Main datasets:**
- `edificio.shp`
- `division_altura.shp`
- `Edificios_XXX.csv`

**Purpose:** Building geometries, cadastral divisions and associated building attributes.

## 2. Digital Surface Models

**Source:** National Geographic Information Centre (CNIG), Spain.

**Dataset:** MDSnE2 2.5 second coverage.

**Purpose:** Surface information used in the geometric characterization workflow.

## 3. Climatic Data

**File:** `ArchivoClimatico.xlsx`.

**Main variable:** `OutTemp`.

**Purpose:** Outdoor temperature information used to calculate Heating Degree Days (HDD).

The original climatic data source and its temporal coverage must be documented after verification.

## 4. Data Documentation

For each dataset, record:

- Original source and download URL.
- Download or acquisition date.
- Spatial and temporal coverage, where applicable.
- Coordinate reference system, where applicable.
- Usage licence and redistribution conditions.
- Any preprocessing or modifications performed.
