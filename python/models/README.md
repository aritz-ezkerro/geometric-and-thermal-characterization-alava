# Predictive Models

This folder contains the trained machine learning models used in the thermal characterization of the residential building stock of Álava.

## Main Model

The original methodology uses a trained model stored in:

`modelo_TB.pkl`

The model is loaded using the Python `joblib` library and is used to predict the base temperature of each building.

## Model Documentation

The following information should be documented when the model is added:

- Model type and architecture.
- Training dataset and geographical scope.
- Input variables.
- Target variable.
- Training and validation procedure.
- Model performance metrics.
- Software dependencies.

## Reproducibility

The original model file should be preserved without modification.

Any updated or retrained models should be clearly identified and documented separately.
