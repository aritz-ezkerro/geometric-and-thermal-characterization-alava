# Python Scripts

## 1. Overview

This directory contains the Python scripts used for the thermal characterization of the residential building stock of Álava.

The main execution script is `Script_SPYDER.py`, which processes the geometric parameters generated by QGIS and applies a predictive model to estimate building thermal characteristics and energy demand.

## 2. Main Script

### 2.1. Script_SPYDER.py

The script performs the following operations:

1. Requests the directory containing the original input files.
2. Requests the directory containing the modified datasets generated by QGIS.
3. Loads the trained predictive model stored in `modelo_TB.pkl`.
4. Exports the XGBoost model to JSON format.
5. Loads the geometric parameters from `Parametros_Edificios.csv`.
6. Predicts the base temperature of each building.
7. Calculates Heating Degree Days (HDD) using the climatic data.
8. Estimates the energy demand of each building.
9. Exports the resulting datasets.

## 3. Input Data

The script requires the following files:

| File | Description |
|---|---|
| `modelo_TB.pkl` | Trained predictive model |
| `ArchivoClimatico.xlsx` | Outdoor temperature time series |
| `Parametros_Edificios.csv` | Geometric parameters used for base temperature prediction |
| `Parametros_Edificios_2.csv` | Thermal parameters used for energy demand estimation |

The climate dataset must contain the `OutTemp` variable and a `Date/Time` index.

## 4. Thermal Modelling Workflow

### 4.1. Base Temperature Prediction

The trained model predicts the base temperature of each building.

The predictions are stored in:

`Parametros_Edificios_TB.csv`

### 4.2. Heating Degree Days

Heating Degree Days are calculated using the predicted base temperature and outdoor temperature time series.

For each building:

\[
HDD = \frac{\sum_t \max(T_B-T_{out,t},0)}{24}
\]

This expression assumes hourly climate data.

The results are stored in:

`Parametros_TB_HDD.xlsx`

### 4.3. Energy Demand Estimation

The energy demand is estimated using the thermal parameter `UA + ρVcp` and the calculated HDD values.

\[
E = (UA+\rho Vc_p)\cdot HDD\cdot 24
\]

The resulting estimates are expressed in kWh, provided that the thermal parameter is expressed in kW/K and the HDD calculation uses the stated convention.

The final results are stored in:

`Predicciones_Edificios.xlsx`

## 5. Output Files

| File | Description |
|---|---|
| `Parametros_Edificios_TB.csv` | Predicted base temperature for each building |
| `Parametros_TB_HDD.xlsx` | Calculated Heating Degree Days |
| `Predicciones_Edificios.xlsx` | Estimated building energy demand |

## 7. Execution Notes

- Run the script using the Python environment configured for the predictive model.
- Ensure that all required input files are available.
- Check that the two geometric parameter datasets correspond to the same buildings and preserve the same order.
- Verify that the climate data has the expected temporal resolution.
- Preserve the original trained model and input datasets.
