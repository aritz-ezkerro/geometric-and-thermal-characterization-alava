# Output Data

This folder contains the datasets generated by the geometric and thermal characterization workflows.

## Expected Outputs

The main output files include:

- `Parametros_Edificios.csv`
- `Parametros_Edificios_2.csv`
- `Parametros_Edificios_TB.csv`
- `Parametros_TB_HDD.xlsx`
- `Predicciones_Edificios.xlsx`

## Final Results

The main result is the estimated annual heating energy demand for each building, expressed in kWh.

## Data Management

- Preserve the original input datasets.
- Keep intermediate files separate from final results.
- Document the processing date and software environment.
- Avoid committing large or sensitive datasets without checking their redistribution conditions.

The actual output files will be added after the processing workflow has been tested.
