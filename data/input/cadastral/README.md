# Cadastral Input Data

This folder contains the cadastral datasets required for the geometric characterization of the residential building stock of Álava.

## Required Files

- `edificio.shp`: cadastral building geometries.
- `division_altura.shp`: building divisions and height information.
- `Edificios_XXX.csv`: additional cadastral attributes.

## File Organization

Keep all files associated with each shapefile together. These may include `.shp`, `.shx`, `.dbf` and `.prj` files.

## Data Management

Preserve the original datasets and document their source, download date, coordinate reference system and any preprocessing performed.

Check the applicable data-use conditions before redistributing cadastral information.
