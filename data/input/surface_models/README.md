# Digital Surface Model Input Data

This folder contains the digital surface model (DSM) raster datasets used in the geometric characterization workflow.

## Required Files

The original methodology uses raster files named:

`NDSM-EDIFICIOS-XXX.tif`

These datasets are based on the MDSnE2 2.5 second coverage provided by Spain's National Geographic Information Centre (CNIG).

## Data Preparation

- Preserve the original raster files.
- Keep all raster tiles required for the study area.
- Check their coordinate reference system, spatial resolution and coverage.
- The QGIS workflow combines the required raster tiles during processing.

## Data Source

National Geographic Information Centre (CNIG), Spain.

The specific dataset version and download information should be recorded when the original raster files are added.
