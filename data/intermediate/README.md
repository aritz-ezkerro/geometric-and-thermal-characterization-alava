# Intermediate Data

This folder is intended for temporary and intermediate datasets generated during the geometric and thermal characterization workflows.

## Purpose

Intermediate files are produced during the QGIS and Python processing stages. They support the transformation of the original input datasets into the final building-level results.

## Data Management

- Keep intermediate files separate from original input datasets.
- Do not modify or overwrite original input data.
- Document important processing outputs when necessary.
- Remove temporary files when they are no longer required.

The original QGIS workflow generates modified datasets in a separate processing folder. These files should be managed carefully when restarting the workflow.
