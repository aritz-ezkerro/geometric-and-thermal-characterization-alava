# Maps

This folder contains spatial visualizations of the residential building stock of Álava.

## Planned Contents

- Building footprint maps.
- Maps of geometric building characteristics.
- Maps of predicted thermal parameters.
- Maps of estimated annual heating energy demand.
- Municipal-level spatial summaries.

## Map Documentation

Each map should include:

- A descriptive title.
- The geographical area represented.
- The variables displayed and their units.
- The data sources.
- The coordinate reference system.
- The date of production.

Maps should be exported in suitable formats for visualization and publication.
