# Results and Visualizations

This folder contains the maps, figures and tables produced from the geometric and thermal characterization of the residential building stock of Álava.

## Planned Contents

- Maps showing the spatial distribution of building characteristics.
- Maps of estimated annual heating energy demand.
- Figures illustrating the main results.
- Tables containing statistical summaries.

## Organization

Visual outputs will be organized into dedicated subfolders:

- `figures/`
- `tables/`
- `maps/`

## Reproducibility

Each result should be associated with the input datasets, processing workflow and software environment used to generate it.
